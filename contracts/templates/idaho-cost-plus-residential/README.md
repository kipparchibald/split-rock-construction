# Idaho cost-plus residential construction agreement (template)

Reusable Split Rock Construction LLC packet pattern, first proven on **Holwege Lot 16**.

## Use for a new job
1. Copy this folder to `contracts/<JobName>/`.
2. Replace Owner names, Property legal, dollars, schedule, and Exhibit B lines.
3. Keep Art. 3.4 (cost-plus / Estimates) and dual-capacity initials if Archibald-Bagley lot sale applies.
4. Export letterhead PDF into `public/<job-slug>/` and register in the job’s `documents` seed.
5. Do **not** invent dollars — pull from the signed job sheet only.
